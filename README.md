# Text to Speech App

A Streamlit web app that converts text to speech using Google Text-to-Speech (gTTS).

## Features
- Enter text directly or upload a text file
- Generate speech and play it in the browser
- Download the generated MP3 file

## Prerequisites
- Python 3.7+
- Streamlit
- gTTS

## Installation
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`

## How to run locally
Run `streamlit run txtToSpeech.py`

## Deployment
Deploy to Streamlit Cloud:
1. Push this code to a GitHub repository
2. Go to [share.streamlit.io](https://share.streamlit.io)
3. Connect your GitHub repo
4. Deploy
